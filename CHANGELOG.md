# Изменения

## Следующая визуальная итерация

- Камера за спиной героя с поворотом мышью и касанием вместо высокого ракурса.
- Закрытый каменный зал с арками, факелами, туманом и текстурами PSX Dungeon 64×64.
- Собственные фигуры в плащах с человеческими пропорциями вместо персонажей Kenney.
- Отдельный ракурс пошагового боя и открывающаяся после победы решётка.
- Короткий гостевой автопоказ для записи настоящего игрового процесса.
- Пауза содержит источники материалов и лицензию CC BY 4.0.

Приоритет дальнейшей работы: короткая запись демки, обратная связь и исправления.
Визуальное направление пока не утверждено владельцем.

## 0.1.0

Первый локальный прототип «Нулевой архив».

- Один 3D-зал, фиксированный ракурс, герой и страж из набора Kenney CC0.
- Ходьба с клавиатуры и экранного стика, взаимодействие с объектами.
- Один пошаговый бой, три действия, видимое намерение противника.
- Две пасхалки и выход после победы.
- Подтверждение Telegram initData, отдельный гостевой режим для локальной проверки.
- Серверный расчёт счёта и защита от повторного применения хода.
- Версии лидерборда, лучший результат аккаунта и общие места при ничьей.
- Docker Compose, постоянный том SQLite, сборка и тесты в GitHub Actions.

Призовой режим закрыт. HTTPS, фактический запуск из Telegram и ручная проверка
полного маршрута остаются отдельными задачами. Музыка и модели временные.
