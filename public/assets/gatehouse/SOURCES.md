# Чёрные ворота

Для проекта с помощью ImageGen создан один исходный атлас камня, просмолённого дуба и мостовой. Четыре квадрата экспортированы в локальные цветовые карты WebP 256×256. Освещение, туман и затенение добавляет движок. Исходные цвета рассчитаны на рассеянный дневной свет.

| Файл | Поверхность |
| --- | --- |
| `ashlar.webp` | Тёсаные блоки башен, ворот и остатков лесной стены |
| `black-oak.webp` | Вертикальные доски и внутренние поперечины створок |
| `causeway.webp` | Булыжники подступа и проезда |
| `dressed-stone.webp` | Угловые камни, перемычка, плита под ключ и обломки мощения |

Геометрия надвратной башни, ковка и тканый знак веретена созданы в [модуле ворот](../../../src/gatehouse.ts). Визуальный ориентир для масштаба кладки, глубины фасада и света над лесом взят из [официальной галереи PRISON OF HUSKS](https://store.steampowered.com/app/2975260/PRISON_OF_HUSKS/).
