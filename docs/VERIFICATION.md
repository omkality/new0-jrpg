# Проверки демки движения и боя

Состояние на 15 ноября 2026 года. Локальная демонстрационная итерация, без призовых результатов.

## Автоматические проверки

- Production-сборка TypeScript/Vite прошла.
- 11 Node-тестов: дальность и однократное попадание меча, непрерывный ход времени,
  уклонение и его окно неуязвимости, буфер уклонения, расход выносливости,
  независимое от частоты обновления движение, границы комнаты, замах противника,
  смерть и повтор. Также удержание клавиш, нормализация диагоналей, стик,
  отдельные указатели камеры/движения, отмена касания, различие тапа и обзора,
  отпускание блока при отмене pointer.
- 29 API-тестов в Docker прошли. Они покрывают подтверждение Telegram и прежний
  пошаговый ruleset, а не защищённость нового локального боя.
- Контейнер с последней сборкой работает на 127.0.0.1:8085.

## Фактический браузерный просмотр

В браузере приложения пройден автоматический сценарий через реальные команды
движения/атаки/уклонения: приближение, бой, смерть противника, подъём решётки,
выход и финальная панель. Координаты, HP и победа не подставлялись.
Просмотрены контактные листы записи по всей боевой части. Масштаб персонажа при
смерти не меняется, тело остаётся на полу, оружие отпускается.

Вручную через интерфейс проверены удержание W, удержание экранного стика,
его отпускание, нажатие атаки и уклонения, прохождение шагов обучения.
После отпускания стика transform ручки сбрасывается, движение не остаётся зажатым.
Просмотрены 1280×720 и 390×844. Физический touch телефона не имитировался.

WebGL сообщает ANGLE Direct3D11 и NVIDIA GeForce RTX 4070 Ti SUPER.
На этом ПК во время просмотра счётчик показывал около 165 FPS, p95 интервалов
кадров около 6,2 мс, до 60 draw calls и примерно 63 тысячи треугольников.
Это измерение интервалов requestAnimationFrame в текущем браузере, не измерение
чистого GPU-времени и не результат на телефоне.

Запись делается самим приложением через canvas.captureStream(60), без последовательности
редких скриншотов. Фактический исходный файл содержит около 59,2 кадра/с.
Финальный MP4 экспортирован через h264_nvenc в постоянные 60 FPS, 1280×720,
20 секунд, 1200 кадров. Незначительные пропуски исходного захвата компенсируются
при приведении к постоянной частоте, это не доказывает отсутствие пропусков на всех устройствах.
Полный экспорт декодирован FFmpeg без ошибок. Видео без звука.

В последнем браузерном просмотре ошибок JS/WebGL нет. Вызовы Telegram-only API
защищены наличием initData, чтобы обычный браузер не выдавал предупреждения SDK.

## Что ещё не подтверждено

- Физические Android/iPhone: устойчивые 60 FPS, нагрев, многопальцевый ввод,
  поворот экрана и поведение Telegram WebView.
- Полное ручное прохождение всех комбинаций действий и двух отголосков.
- Качество конечных анимаций и окончательный художественный образ. Три новых
  клипа представляют собой блокинг на настоящем скелете, не готовый mocap.
- Реальный вход из @new0_game по публичному HTTPS.
- Серверная проверка realtime-ввода и отдельная версия призового ruleset.
- Ограничение зачётных попыток, ничьи и период конкурса.
- Средняя длительность прохождения на новых игроках.

Текущий клиент использует API для идентификации. Локальный realtime-бой не отправляет
свои HP/победу/очки в сохранённый пошаговый API. Его результаты не участвуют в рейтинге.
Старые тестовые результаты в постоянном томе сохранены.
