# Проверки пластики боя, площадок и Mini App

Состояние на 15 ноября 2026 года. Демонстрационная итерация без призовых результатов.

## Сборка и автоматические проверки

- Production-сборка TypeScript/Vite прошла.
- 23 Node-теста прошли. Покрыты отдельный, двойной и тройной удары, стыки с
  авторским контрактом, контакт и восстановление, запрет блока внутри цепочки,
  выносливость, уклонение, непрерывное движение и отмена указателей. Автопоказ
  через обычные команды доходит до победы и выхода, персонаж завершает движение.
- Проверены реальные интервалы кадров в диагностике, длинные кадры и прерывание
  автопроверки. Отдельно воспроизведены таймаут и обрыв успешного JSON-ответа.
  Без повторного подключения регрессионные проверки падают, с ним проходят.
  Неверная подпись Telegram не повторяется и не понижается до гостевого входа.
  Обычные игровые POST не воспроизводятся автоматически при сетевом сбое.
- 32 API-теста в Docker прошли. Проверены идентификация, прежний серверный бой,
  конфигурация ссылок и бота, доступ к диагностике только владельцу, ограниченные
  поля, срок доступа к отчёту и отсутствие созданных игровых прохождений.
  Есть предупреждение Starlette TestClient о будущем переходе с httpx на httpx2.
- `verify_compose.py` поднял отдельный временный проект с API на 18001, nginx
  на 18080 и автоматически выбранным портом публикации. Оба wget healthcheck,
  nginx-прокси и полный HTTP smoke прежнего API прошли. Временные данные удалены,
  основные и preview-тома сохранены.
- Проверка бейджей совпала с зависимостями. Все восемь SVG вернули HTTP 200.

## Ассеты и просмотр

В игре просмотрены три площадки с разной архитектурой и палитрой. Выполнены
боевые записи с носильщиком, смотрителем и пустой куклой. Просмотрены контактные
листы движений, контакта, смерти и выхода. В последнем просмотре ошибок и
предупреждений JS/WebGL нет.

Из моделей героини и смотрителя удалены скрытые задние волосы. Геометрическая
проверка находит ноль проблемных треугольников. Имена костей, rest TRS,
inverse-bind matrices, одежда и анимационные данные сохранены. На свежем
рендере пучка под головным убором нет. Контентный хэш в адресах ассетов исключает
показ старых GLB из суточного браузерного кэша после замены файла.

Во всех трёх наборах движений по 13 клипов, без анимированного масштаба.
Максимальное численное расхождение weighted-поверхности в стыках около
3,19 × 10⁻⁷ м. Падение сохранено по значениям каналов. Проверки не заменяют
оценку пластики и пересечений одежды в крайних позах.

## Реальный iPhone в Telegram

Первый запуск дошёл до успешной проверки Telegram-подписи на сервере,
но на клиенте завершился `Fetch is aborted`. Точная причина сетевого обрыва
не установлена. Вход отделён от загрузки крупных GLB, таймаут увеличен до
30 секунд и настраивается через окружение, добавлены ограниченные повторы
подключения и кнопка повторной загрузки. Адрес кнопки бота включает текущую
сборку, чтобы Telegram открывал обновлённый клиент.

После обновления владелец запустил автопроверку на своём iPhone.
Сервер получил настоящий отчёт: платформа `ios`, viewport 393×720,
пять touch points, проверенные Telegram initData. Значение `telegram_version`
в JSON является версией Bot API из WebApp.version, а не версией iOS или клиента.

| Место | Средний FPS | p95 | Кадров >25 мс | Завершено |
| --- | ---: | ---: | ---: | --- |
| Малахитовый неф | 60,09 | 17 мс | 0 | Да |
| Багровые крыши | 60,09 | 17 мс | 0 | Да |
| Двор забвения | 60,09 | 17 мс | 0 | Да |

Масштаб рендера 1,0 на всех площадках. Ошибок JS и потерь WebGL-контекста нет.
Отчёт не прерван, сенсорные элементы помещаются в экран. Измерено примерно
14 секунд на площадку после секундного прогрева. Это короткий автопроход,
удобство одновременных касаний и субъективное ощущение боя оцениваются отдельно.

Для сравнения, автоматический проход в окне браузера 390×844 на RTX 4070 Ti SUPER
показал около 165 FPS с p95 6,2 мс. Этот результат отделён от iPhone-замера.
Запуск в Telegram Desktop средствами UI не подтверждён: захват окна завершался
таймаутом, переход tg:// был запрещён политикой браузерного инструмента.

## Короткие записи

Подготовлены три MP4 по 16 секунд, 1280×720, 60 FPS, по 960 кадров.
Исходники получены из настоящего движка рекордером WebCodecs: 20 секунд,
1200 принятых шагов. Он запрашивает аппаратный кодек и ждёт backpressure.
Экспорт выполнен через h264_nvenc на RTX 4070 Ti SUPER. Каждый файл полностью
декодирован без ошибок. Интерполяция и добавление кадров для смены FPS не применялись.
Видео без звука. Фиксированный шаг записи не используется как бенчмарк.

## Ограничения и следующие проверки

- Полировка силуэтов движения и пересечений одежды продолжается по записи владельца.
- Нужны другие физические устройства, включая Android, и более длинный замер нагрева.
- Текущий бой локальный и не участвует в призовом рейтинге. Серверная проверка
  нового ввода, версия правил, лимит попыток и ничьи остаются отдельной работой.
- Диагностические метрики клиента не являются доверенными призовыми очками.
- Туннель временный, требует работающего компьютера и Docker. Стабильный хостинг
  и окончательный адрес дропа ещё не настроены.
